# Дизайн-интервью Humans vs AI

Этот каталог хранит банк из 1000 вопросов, подтверждённые ответы и состояние интервью.

## Приоритет решений

1. Подтверждённые ответы гейм-дизайнера.
2. Зафиксированные исходные решения в `fixed-decisions.json`.
3. Вопросы и рекомендации банка.
4. `game_design_bible_ru.md` и `the-first-truly-epic-war-canonical-gdd-ru.md` как источники гипотез и противоречий.
5. Текущая реализация.

## Формат работы

- 1000 вопросов задаются по 10 за раунд, от глобальных решений к деталям реализации.
- У каждого вопроса есть варианты, рекомендация, возможность отложить решение и собственный ответ.
- После каждого раунда ответы сохраняются, а зависимые последующие вопросы при необходимости уточняются.
- Итоговый документ разработки формируется только из подтверждённых решений; предположения маркируются отдельно.

## Артефакты

- `fixed-decisions.json` — исходные подтверждённые решения.
- `interview-state.json` — текущий прогресс.
- `question-bank/part-*.jsonl` — последовательные части банка вопросов.
- `question-bank-manifest.json` — порядок частей и контрольное количество.
- `answers/round-*.json` — ответы по завершённым раундам.
