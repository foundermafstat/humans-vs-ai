## 1. Короткий вывод

Идея игры сильная: это не просто голосование за фракцию, а социальная игра с публичным штабом, скрытым приказом, дезинформацией, шпионами и ИИ, который читает открытые комментарии. Главный виральный крючок:

```txt
То, что игрок пишет в Reddit-комментариях, становится частью боя.
```

На текущий момент в коде реализован не полный дневной цикл, а dev-прототип:

- создание war-room поста;
- три ветки комментариев: AI / Green / Blue;
- тестовые app/user комментарии;
- выдача Green flair;
- отдельная матрица доктрин в `doctrines.ts`.

Ключевые механики пока не связаны в единый loop:

- скрытый выбор доктрины;
- дневной раунд;
- подсчет кармы комментариев;
- AI Awareness;
- выбор контрдоктрины ИИ;
- шпионы;
- расчет результата;
- награды и итоговый battle report.

## 2. Фактическая математика доктрин

В `game/src/server/core/doctrines.ts` сейчас задано 7 доктрин:

```txt
STRIKE
HACK
VIRUS
PHANTOM
SHIELD
OVERLOAD
TRAP
```

Каждая доктрина:

- побеждает ровно половину остальных доктрин;
- проигрывает ровно половине остальных доктрин;
- дает ничью против самой себя.

Это математически ровная турнирная матрица на 7 состояниях.

Для случайного выбора одной стороны:

```txt
P(win)  = 3/7
P(loss) = 3/7
P(draw) = 1/7
```

Это хорошая база: ни одна доктрина не является доминирующей, а победа зависит от чтения противника, скрытой координации и модификаторов.

Главная проблема раннего состояния была в расхождении документов и кода. Теперь целевая модель зафиксирована: код и документы должны строиться вокруг 7 доктрин.

## 3. Трехсторонний дневной бой

В дневном раунде участвуют:

```txt
Green Division
Blue Division
AI
```

Каждая сторона сравнивает свою доктрину с двумя оппонентами:

```txt
Green vs Blue
Green vs AI
Blue vs AI
```

Рекомендуемая базовая формула:

```txt
doctrineScore(side) =
  pairScore(sideDoctrine, opponentA)
  + pairScore(sideDoctrine, opponentB)

pairScore:
  win  = +25
  loss = -20
  draw = 0
```

Возможные значения для одной стороны:

| Исход против 2 оппонентов | Doctrine score |
|---|---:|
| 2 победы | +50 |
| победа + ничья | +25 |
| победа + поражение | +5 |
| 2 ничьи | 0 |
| ничья + поражение | -20 |
| 2 поражения | -40 |

Порог победы нужен обязательно:

```txt
WIN_THRESHOLD = 8..12
```

Если разница между первым и вторым местом меньше порога, территория должна остаться спорной. Это защищает игру от случайных побед на тонких модификаторах.

## 4. Социальная модель: публичный сигнал против скрытого приказа

Сильнейшая часть игры не в самой RPS-матрице, а в конфликте двух каналов:

```txt
Публичные комментарии = видимый сигнал
Скрытый интерфейс = реальный приказ
```

Игроки могут:

- публично обсуждать одну доктрину;
- скрыто выбрать другую;
- создавать шум;
- пытаться вычислить шпионов;
- пытаться ввести ИИ и другую дивизию в заблуждение.

Это превращает обычные Reddit-комментарии в игровое поле.

Математически каждой дивизии нужен вектор:

```txt
hiddenDistribution = реальные скрытые приказы по доктринам
publicSignal       = доктрины, упомянутые в комментариях
```

Пример:

```txt
hiddenDistribution:
  STRIKE   52%
  SHIELD   18%
  PHANTOM  12%
  others   18%

publicSignal:
  HACK     46%
  VIRUS    21%
  STRIKE    8%
  others   25%
```

Если скрытая доктрина хорошо скоординирована, но публичный сигнал указывает на другое, дивизия получает deception value.

## 5. AI Awareness

ИИ не должен идеально читать игроков. Если ИИ всегда выбирает идеальную контрдоктрину, casual-игроки будут чувствовать, что их наказывают за участие в комментариях.

Лучше считать `AI Awareness` от 0 до 100 для каждой дивизии.

Источники роста:

- публичные комментарии совпадают с реальным скрытым приказом;
- одна доктрина слишком явно доминирует в комментариях;
- скрытый выбор переполнен одной доктриной;
- шпион успешно толкает дивизию к раскрытию;
- мало Counterintelligence / Noise действий.

Источники снижения:

- публичный сигнал отличается от реального приказа;
- комментарии создают качественный шум;
- дивизия не перегружает один очевидный приказ;
- игроки используют защитные/контрразведывательные действия;
- шпион не смог создать читаемый паттерн.

Практичная модель:

```txt
aiAwareness =
  exposureScore
  + publicConfidence
  + hiddenOvercrowd
  + spyLeak
  - deceptionScore
  - counterIntel
  - usefulNoise
```

Эффект:

| AI Awareness | Эффект |
|---:|---|
| 0-30 | ИИ плохо читает дивизию, counter bonus снижен |
| 31-60 | нейтральный режим |
| 61-80 | ИИ часто выбирает правильный counter |
| 81-100 | ИИ почти уверен, получает bonus и taunt |

Важно: даже при высоком awareness ИИ лучше делать вероятностным, а не абсолютно детерминированным.

## 6. Координация для 7 доктрин

Старые thresholds из ранней упрощенной модели нельзя переносить напрямую на 7 доктрин.

Для 7 доктрин случайное распределение дает примерно:

```txt
1 / 7 = 14.3% на доктрину
```

Значит, `primaryShare < 40%` как "слабая доктрина" слишком жестко для ранней игры. Рекомендуемая таблица:

| Состояние | Условие | Эффект |
|---|---:|---:|
| Распад приказов | primary < 25% | -15 |
| Слабая координация | 25-35% | -5 |
| Рабочая координация | 35-55% | +8 |
| Сильная координация | 45-65% и есть decoy-сигнал | +15 |
| Предсказуемость | 65-75% | 0 или -5 |
| Переполнение | >75% | -15 и рост AI Awareness |

Идеальный диапазон для социальной игры:

```txt
реальный primary: 45-60%
публичный decoy: 35-55%
```

Так игрокам нужно договариваться, но не превращать раунд в очевидное голосование.

## 7. Карма комментариев

Пользовательская карма может стать сильным мотиватором, но ее нельзя напрямую превращать в боевую силу. Иначе появятся:

- snowball у популярных игроков;
- давление на новичков;
- бригадинг;
- токсичные минусы против "подозрительных" игроков;
- слишком простое вычисление шпионов.

Лучше использовать карму как reputation-сигнал с лимитами.

Рекомендуемая модель:

```txt
commentWeight = clamp(log1p(upvotes - downvotes), 0, cap)
```

Где `cap` ограничивает влияние одного комментария.

Карма должна влиять на:

- публичный вес сигнала;
- Command Reputation;
- медали и прогресс;
- шанс стать временным лидером/аналитиком;
- косметический статус.

Карма не должна сильно влиять на:

- вес скрытого приказа;
- шанс победы в одиночку;
- публичное раскрытие шпионов;
- наказание игрока за непопулярное мнение.

## 8. Шпионы

Шпионская механика очень виральная, но самая рискованная.

Правильная роль шпиона:

```txt
Шпион не ломает игру один.
Шпион меняет вероятность ошибки дивизии.
```

Шпион может:

- продвигать плохую доктрину;
- усиливать публичный сигнал, который читает ИИ;
- создавать ложный консенсус;
- поддерживать неправильного лидера;
- помогать ИИ или другой дивизии.

Шпион не должен:

- раскрываться по имени;
- получать кнопку "саботировать";
- автоматически писать комментарии;
- быть целью публичной охоты;
- быть единственной причиной поражения.

Рекомендуемый лимит:

```txt
spyScore = -15..+10
```

То есть успешный шпион заметно влияет на исход, но не перекрывает полностью доктрину и координацию.

## 9. Почему механика виральна

У игры есть несколько сильных органических крючков:

1. **Комментарии являются gameplay.** Игрок не просто пишет мнение, а влияет на AI Awareness и публичный сигнал.
2. **Открытый штаб видят враги.** Любой комментарий может помочь своей стороне или раскрыть план.
3. **ИИ как антагонист читает людей.** Это понятно, современно и легко объясняется в одном предложении.
4. **Шпионы создают истории.** После раунда игроки обсуждают, был ли план сорван изнутри.
5. **Ежедневный цикл создает привычку.** Игроку достаточно зайти раз в день, оставить приказ и комментарий.
6. **Battle report легко шарить.** Итог "мы обманули ИИ" или "ИИ прочитал вас" хорошо работает как Reddit-контент.
7. **Фракционная идентичность.** Green/Blue, flair, паспорт, медали и ранги дают социальное закрепление.

Главная формула виральности:

```txt
публичный спор + скрытый выбор + ИИ-контрудар + итоговый отчет
```

## 10. Главные проблемы текущей модели

### 10.1. Статус source of truth

Source of truth теперь зафиксирован: MVP и полноценная версия строятся на 7 доктринах из `game/src/server/core/doctrines.ts`.

Старые упоминания ранней упрощенной модели остаются историческим контекстом и не должны использоваться как активное требование.

Если оставлять 7 сразу, нужен очень понятный UI: "эта доктрина бьет X/Y/Z и проигрывает A/B/C".

### 10.2. Нет реализованного core loop

Сейчас нет связки:

```txt
join division
daily battle
public discussion
hidden doctrine vote
AI scan
spy influence
resolution
reward
battle report
```

Без этой связки игра пока выглядит как визуальный прототип и dev war-room, а не социальная стратегия.

### 10.3. ИИ может стать слишком сильным

Если ИИ всегда точно читает публичный план и всегда выбирает counter, игроки быстро поймут, что говорить правду нельзя. Тогда комментарии станут искусственным шумом.

Нужен баланс:

```txt
ИИ должен быть опасным, но ошибающимся.
```

### 10.4. Скрытый выбор может убить комментарии

Если победа зависит только от hidden vote, игроки перестанут обсуждать. Если победа зависит только от комментариев, скрытый интерфейс не нужен.

Нужно, чтобы оба канала были важны:

- hidden vote определяет реальную доктрину;
- comments определяют exposure, deception, morale, AI Awareness и battle report.

### 10.5. Шпионы могут вызвать токсичность

Игроки начнут обвинять друг друга, особенно если есть negative karma. Нужны жесткие ограничения:

- не показывать ник шпиона;
- не давать кнопку обвинения;
- не награждать за травлю;
- показывать только агрегаты: `Spy influence: Low/Medium/High`.

### 10.6. Daily cadence может быть слишком медленным

Один бой в день хорош для ритуала, но слаб для первой сессии. Нужна демо-фаза или mini-conflict:

- daily main battle;
- короткие тренировочные skirmish-раунды;
- preview/forecast до финального расчета;
- итоговый report после закрытия дня.

## 11. Как усилить участие игроков

### 11.1. Дать каждому игроку понятный ежедневный чеклист

```txt
1. Выбери скрытую доктрину.
2. Оставь публичный сигнал или decoy.
3. Оцени комментарии союзников.
4. Проверь AI forecast.
5. Вернись за battle report.
```

### 11.2. Награждать не только победителей

Игрок должен получать прогресс за:

- участие в daily battle;
- точный прогноз;
- успешный decoy;
- комментарий с высокой кармой;
- дисциплину шума;
- участие в проигранном, но близком бою;
- серию дней.

### 11.3. Сделать роли внутри дивизии

Легкие роли без сложного интерфейса:

| Роль | Что делает |
|---|---|
| Commander | предлагает публичную линию |
| Analyst | пишет прогноз по доктринам |
| Noise Maker | создает decoy-сигнал |
| Counterintel | снижает AI Awareness |
| Scout | помогает читать другую дивизию |

Роли могут быть временными daily badges, а не постоянными классами.

### 11.4. Сделать battle report главным reward-моментом

После дня игроки должны увидеть:

```txt
Green chose: hidden doctrine
Blue chose: hidden doctrine
AI chose: doctrine
Public signal said: doctrine/noise
AI Awareness: Low/Medium/High
Spy influence: none/low/medium/high
Winner: side
Why: 2-3 короткие причины
```

Важно: report должен объяснять исход, но не раскрывать персональные обвинения.

### 11.5. Добавить "мы обманули ИИ" как отдельную победу

Даже если дивизия не заняла первое место, она может получить achievement:

```txt
AI Misread
Public signal: HACK
Actual doctrine: SHIELD
AI countered the wrong target
```

Это усиливает комментарии и делает проигрыш менее пустым.

## 12. Рекомендуемая итоговая формула

```txt
finalScore(side) =
  doctrineScore
  + coordinationScore
  + aiAwarenessModifier
  + commentSignalScore
  + spyScore
  + karmaSignalScore
  + dailyMomentumScore
```

Где:

```txt
doctrineScore        = результат матрицы доктрин против 2 сторон
coordinationScore    = качество скрытого распределения приказов
aiAwarenessModifier  = бонус/штраф в боях против ИИ
commentSignalScore   = deception - exposure + usefulNoise
spyScore             = ограниченное влияние шпиона
karmaSignalScore     = capped reputation комментариев
dailyMomentumScore   = streak/participation без pay-to-win эффекта
```

Рекомендуемые лимиты:

| Компонент | Диапазон |
|---|---:|
| doctrineScore | -40..+50 |
| coordinationScore | -15..+15 |
| aiAwarenessModifier | -10..+15 |
| commentSignalScore | -12..+12 |
| spyScore | -15..+10 |
| karmaSignalScore | -5..+8 |
| dailyMomentumScore | 0..+5 |

Доктрина должна оставаться самым важным фактором, но социальная игра должна быть достаточно сильной, чтобы игроки спорили, скрывали планы и возвращались.

## 13. Приоритеты реализации

### P0: закрепить 7 доктрин в contracts и UI

Целевой набор уже выбран:

```txt
STRIKE / HACK / VIRUS / PHANTOM / SHIELD / OVERLOAD / TRAP
```

Следующий шаг: сделать UI выбора 7 доктрин и shared contracts источником правды для client/server payloads.

### P1: реализовать hidden doctrine vote

Минимально:

- игрок выбирает Green/Blue;
- один скрытый приказ в день;
- повторный выбор перезаписывает приказ до lock time;
- после lock time выбор закрывается.

### P2: подключить `getDoctrineMatchup` к расчету результата

Нужен resolver, который берет:

```txt
greenDoctrine
blueDoctrine
aiDoctrine
```

И возвращает:

```txt
pairwise results
doctrineScore
winner/contested
```

### P3: добавить агрегаты комментариев

Не хранить полный текст как основной state. Хранить агрегаты:

```txt
mentions by doctrine
positive/negative karma aggregate
noise score
direct call score
spy keyword aggregate
```

### P4: добавить AI Awareness и вероятностный AI counter

ИИ должен выбирать counter не всегда, а по confidence.

```txt
low awareness    -> random/thematic doctrine
medium awareness -> weighted counter
high awareness   -> strong counter
```

### P5: добавить безопасную spy loop

Минимально:

- offer;
- accept/refuse;
- secret panel;
- capped spyScore;
- no public name reveal;
- post-round aggregate disclosure.

### P6: сделать battle report

Это главный retention и virality asset. Без него социальная игра не закрывает эмоциональный цикл.

## 14. Итог

Текущая концепция имеет сильный потенциал, потому что использует нативное поведение Reddit: комментарии, карму, публичные споры, фракционность и ежедневный ритуал. Самая ценная часть игры — не сама матрица доктрин, а напряжение между публичной речью и скрытым приказом.

Главное, что нужно защитить:

```txt
Комментарии должны быть полезны, но опасны.
Скрытый выбор должен быть решающим, но не единственным.
ИИ должен читать игроков, но иногда ошибаться.
Шпионы должны создавать драму, но не травлю.
Карма должна давать статус, но не ломать баланс.
```

Если это соблюсти, игра может стать виральной именно как Reddit-native social strategy, а не как обычная мини-игра внутри webview.
